# Changelog

## v1.0.0 — 2026-04-02

Initial release — marketing adaptation of Three Man Team.

- Three-agent team: Strategist, Copywriter, Designer
- Generic agents in `agents/` with customizable personas and [CUSTOMIZE] placeholders
- Named persona template in `templates/project-folder/` (Sofia, Charlie, Dana)
- Generic clean-slate template in `templates/generic/`
- Structured handoff files: STRATEGY-BRIEF, REVIEW-REQUEST, REVIEW-FEEDBACK, CAMPAIGN-LOG, SESSION-CHECKPOINT
- Token optimization rules baked into every session router
- Setup script with CLAUDE.md instructions printed on install
- Full documentation suite: customization guide, token optimization, campaign walkthrough
- Adapted from [Three Man Team](https://github.com/russelleNVy/three-man-team) v1.0.0

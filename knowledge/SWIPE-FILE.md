# Swipe File — Copy That Worked
*Copywriter's reference library. Grows with each campaign. Read when writing for a specific channel or audience type.*

---

## How to Use

- **Before writing:** grep this file for the channel or audience type you're writing for.
- **After publish:** add winning copy from cleared deliverables (with metrics if available).
- **Tag each entry** with channel, audience, campaign, and what made it work.

## Format

```
### [Channel] — [What it is]
**Campaign:** [name] | **Audience:** [who] | **Result:** [metric or "pending"]

> [The actual copy that worked]

**Why it worked:** [one sentence]
```

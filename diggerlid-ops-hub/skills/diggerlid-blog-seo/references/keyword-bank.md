# Keyword Bank

## How to use this file

- Real Google Keyword Planner data (AU) exists for **grease and KAJO only**. It is below. Use it first for any grease, KAJO or maintenance article.
- For covers, enclosures, PRO Mat, DiggerShield, Draw Bar, Hauler and Wipes there is **no validated volume data yet**. Run the live research in `seo-rules.md` §1. Label any volume you can't source as "unverified".
- Never invent search volumes. Planner volumes are banded (500 means "about 500/mo"). 50/mo keywords with a competition index of 0 to 25 are content gold: low effort, ownable.
